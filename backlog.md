# Recdrop — Backlog

_Formerly "Sound Recorder" (renamed 2026-10-22). The local project folder is still `Sound Recorder/`._

Simple dark-themed desktop app that records system audio, lets you crop the recording, and saves it as MP3 / MP4 / WAV.
Stack: Electron + React + Vite, FFmpeg for MP3/MP4 encoding, electron-builder for the Windows installer.

**Status:** v1.1.0 working; Windows installer at `release/Recdrop Setup 1.1.0.exe`.

---

## 📁 File structure

```
Sound Recorder/
├── electron/                 Desktop side (Node.js / Electron main process)
│   ├── main.cjs              Window, system-audio capture permission, settings (save folder),
│   │                         saving files, FFmpeg conversion to MP3/MP4
│   ├── preload.cjs           Safe bridge exposing file/settings functions to the UI (window.api)
│   └── drag-icon.png         Icon shown while dragging a file out of the app
├── src/                      User interface (React)
│   ├── main.jsx              Entry point, mounts the app
│   ├── App.jsx               Switches between recorder and editor screens; title bar + options button
│   ├── styles.css            All styling (dark theme colors at the top)
│   ├── components/
│   │   ├── Recorder.jsx      Record button, timer, level meter, mic toggle, "Saved" message
│   │   ├── Saved.jsx         Screen after stopping: file card (drag out, rename, play),
│   │   │                     Copy file / Show in folder / Crop / New recording / Delete
│   │   ├── Editor.jsx        Crop editor: waveform, handles, zoom/pan, overview strip, playback,
│   │   │                     format; "crop" mode replaces the saved file, "new" mode = fallback
│   │   ├── Settings.jsx      Options window (change save folder)
│   │   └── Icons.jsx         SVG icons
│   └── lib/
│       ├── recorder.js       Captures system audio + mic, mixes them, returns the recording
│       ├── pcm-worklet.js    Audio worklet that collects raw (lossless) audio samples
│       ├── peaks.js          Calculates waveform bar heights for any zoom range
│       ├── wav.js            Turns the cropped part into a WAV file
│       └── format.js         Time formatting + automatic file names
├── tests/
│   └── e2e-installed.mjs     End-to-end test of the packaged app (record, crop, save all formats)
├── build/icon.png            App / installer icon
├── index.html                HTML page the UI loads into
├── vite.config.js            Vite build settings
├── package.json              Dependencies, scripts (dev / dist) and installer settings
├── README.md                 Project description for GitHub
├── LICENSE                   MIT license
├── docs/                     Screenshots used in the README
├── backlog.md                This file
├── recordings/               Your saved recordings (not part of the code)
├── dist/                     Built UI (generated by `npm run build`)
├── release/                  Installer output (generated by `npm run dist`)
└── node_modules/             Installed libraries (generated by `npm install`)
```

**How the pieces connect:** `Recorder.jsx` → `lib/recorder.js` records audio → `App.jsx` auto-saves it (`lib/wav.js` makes a WAV → `preload.cjs` → `electron/main.cjs` converts to MP3 with FFmpeg) → `Saved.jsx` shows the file → optional `Editor.jsx` crop replaces the file.

## How to run
- Dev: `npm run dev`
- Build installer: `npm run dist` → `release/`
- Test installed app: `npm run test:e2e` (plays short beeps through the speakers, uses the clipboard)
- Test the project without installing: `npm run build`, then `APP_DIR=dev node tests/e2e-installed.mjs`
